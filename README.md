# Анализатор оценок на Dart

Консольное приложение для анализа успеваемости студентов. Демонстрирует синтаксис Dart, типы данных, функции, null safety и коллекции.

## Куксова Софья, ИСП-243

## Как запустить

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/lieute049/Dart_Lab1.git
   ```
2. Перейти в папку:
   ```bash
   cd lab1_dart
   ```
3. Установить зависимости:
   ```bash
   dart pub get
   ```
4. Запустить:
   ```bash
   dart run
   ```

## Что изучили

- статическая типизация и объявление переменных (`int`, `double`, `String`, `bool`)
- строковая интерполяция через `$` и `${}`
- `var`, `final`, `const` — три способа объявления
- null safety: `String?`, проверка через `if`, операторы `?.` и `??`
- коллекции: `List`, `Map`, `Set`
- функции: обычные, стрелочные, с именованными и позиционными параметрами

## Ответы на вопросы

1. **Статическая типизация Dart vs Python.** В Dart тип известен на этапе компиляции, ошибки типов ловятся до запуска. В Python — в рантайме. Практическое преимущество — меньше багов доходит до пользователя.

2. **`String?` / `String`.** `String` не может быть `null`, `String?` — может. С `String?` нужна проверка или операторы `?.` / `??`.

3. **Зачем `final` в Dart.** Компилятор гарантирует, что переменная не будет переназначена. В Python — только договорённость, ошибку никто не поймает.

4. **Именованные параметры `{required String name}`.** Передаются по имени (`name: 'Барсик'`), порядок не важен, `required` обязателен. Позиционные — по порядку (`f('Барсик')`).
